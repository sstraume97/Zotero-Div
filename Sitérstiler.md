# Sitérstiler

Zotero kommer med et lite standardutvalg av CSL-stiler («Style Manager»), og laster ned flere fra [Zotero Style Repository](https://www.zotero.org/styles) etter behov. Disse 25 lå installert i profilen ved sikkerhetskopien 21.7.2026 – filnavn er hentet fra [styles/](https://www.zotero.org/styles)-mappen i Tara-backupen, offisiell tittel er hentet fra `<title>` i selve CSL-filen.

## Generelle/internasjonale stiler

| Fil | Offisiell tittel |
| --- | --- |
| `apa.csl` | APA Style 7th edition |
| `chicago-author-date.csl` | Chicago Manual of Style 18th edition (author-date) |
| `chicago-notes-bibliography.csl` | Chicago Manual of Style 18th edition (notes and bibliography) |
| `chicago-shortened-notes-bibliography.csl` | Chicago Manual of Style 18th edition (shortened notes and bibliography) |
| `modern-language-association.csl` | MLA Handbook 9th edition (in-text citations) |
| `harvard-cite-them-right.csl` | Cite Them Right 12th edition (author-date/Harvard) |
| `elsevier-harvard.csl` | Elsevier (author-date/Harvard, with titles) |
| `ieee.csl` | IEEE Reference Guide, versjon 11.29.2023 |
| `nlm-citation-sequence.csl` | NLM/Vancouver: Citing Medicine 2nd edition (citation-sequence) |
| `iso690-author-date-en.csl` | ISO-690 (author-date, engelsk) |
| `iso690-numeric-en.csl` | ISO-690 (numerisk, engelsk) |
| `iso690-full-note-en.csl` | ISO-690 (fullstendig note, engelsk) |
| `mhra-notes.csl` | MHRA Style Guide 4th edition (notes) |
| `wikipedia-templates.csl` | Wikipedia Templates |
| `nature.csl` | Nature |

## Norske og fagspesifikke norske stiler
Disse er ikke del av Zoteros standardutvalg, og er lastet ned/installert manuelt – naturlig nok siden brukeren jobber med norsk forvaltnings-/rettsvitenskapelig materiale (jf. Høring-/Type-tagsene i [Actions and Tags](Actions-and-Tags/README.md)).

| Fil | Offisiell tittel | Trolig bruksområde |
| --- | --- | --- |
| `norsk-apa-manual.csl` | Norsk APA-manual – APA 7th edition (author-date) | Norsk oversettelse/tilpasning av APA 7 |
| `norsk-apa-manual-note.csl` | Norsk APA-manual – APA 7th edition (note) | Samme, men med fotnoter i stedet for parentes-referanser |
| `norsk-henvisningsstandard-for-rettsvitenskapelige-tekster.csl` | Norsk henvisningsstandard for rettsvitenskapelige tekster – kortnoter (bokmål/nynorsk) | Juridiske tekster, kortform |
| `norsk-henvisningsstandard-for-rettsvitenskapelige-tekster-full-firstnote.csl` | Norsk henvisningsstandard for rettsvitenskapelige tekster – fullstendig førstenote (bokmål/nynorsk) | Juridiske tekster, fullstendig note ved første gangs referanse |
| `universitetet-i-oslo-rettsvitenskap.csl` | Universitetet i Oslo – Rettsvitenskap (bokmål) | UiOs rettsvitenskapelige studieprogram |
| `tidsskrift-for-den-norske-legeforening.csl` | Tidsskrift for Den norske legeforening | Medisinsk fagtidsskrift |
